This project was made in roughly two weeks, mostly with Gemini 3. I transformed 42 books into webpages, using visual design to express the distinct vibe of each one.

The reason I made it came from earlier thoughts about media. Different media can convey different kinds of information and feeling, and you can sense that difference when you engage with them.

If you want something concrete, watch video. If you want efficiency, scroll social feeds. If you want to be moved, listen to music. If you want experience, play games. If you want depth, read books. Do not resist a medium just because it is a medium.

AI makes it possible to translate one medium into another, and people have already tried many versions of this. Among all those media, though, the web, an old medium, keeps drawing my attention back. So I have been running different experiments to see what kinds of things the web can carry.

Vibary is one such rough experiment. I tried to translate another, even older medium, books, into webpages and see what kind of effect that would produce.

This project contains close to 100,000 lines of code, and 99.9% of that code was written by AI. For a product with only frontend, no backend, and fairly independent parts across the site, vibe coding is fully capable of doing the job.

I usually keep multiple editors open at once and let different AIs work in parallel on different tasks. Sonnet 4.5 handles the story arc used to narrate a book, Gemini 3 handles design and frontend, and Codex takes care of the remaining dirty work.

Because the code was written by AI, and because time was limited, the current content and experience of Vibary are incomplete and may contain mistakes. So please explore with some caution, but do not panic. The site is basically harmless.
