# 1 如何理解GPT-3

GPT-3 通过互联网上的数据训练，获得了文本预测的能力，即可以根据前面的文字，预测后面的文字。就像手机输入法一样，例如当你输入「我今天」三个字后，输入法会出现一些候选项，预测你接下来即将说的话，如「晚上、下午、早上」等。但GPT-3更强大和通用，可以处理更多任务，甚至涌现出一些惊人的能力，如模式识别，不过 **本质上仍是一个文本预测器**。

语言是人类思维中很重要的部分，人类将思想转成语言，接着发布在互联网上。 语言背后蕴含着不同的知识、思想和文化，这些知识是跨越时间和地域的，GPT-3 通过语言似乎学会了人类的思维和语言，尽管那只是肤浅的模仿，而不是真正的理解，但不妨碍我们 **借鉴语言学和认知科学的知识，去理解和使用GPT-3**。

> 成功的提示方法需要从语言学、通信学、计算机科学或机器学习中吸收知识和观点，因为**语言模型是所有人类语言输出的总和**。
> —— Laria Reynolds
> 


**ChatGPT 的各种表现和人类极为相像**

ChatGPT连一些常识也不知道，人类也是；ChatGPT算数不好，人类也是（733*818=?）；ChatGPT推理不行，人类也是（思考快与慢的系统1）；ChatGPT经常编造答案，人类也是（神话或无根据的话）；ChatGPT思考太慢了，人类也是（语言思考效率不高）；ChatGPT的上下文有限，人类也是（工作记忆）。有人说，人类懂得根据不同的问题利用不同的工具，但ChatGPT技术上也可以实现。

**向ChatGPT提问的方式应该像和人类交流一样**

> 如果人类不理解其意图，为什么 GPT-3 会理解？这不是心灵感应，提示中的几个词可能属于人类文本的无数流派。（一个有用的思想实验：如果有人突然给你发了一个提示，没有任何其他背景，你会把*它* 解释成什么？一个笑话，一个巨魔，垃圾邮件，或者什么？）提示应该遵循Gricean 的沟通格言-陈述应该是真实的、信息丰富的和相关的。人们不应该抛出无关紧要的细节或不符合逻辑的说法，因为在人类文本中，甚至在小说中，这都暗示着这些细节是相关的，无论涉及它们的叙述多么荒谬。⁠⁠当给定的提示不起作用并且 GPT-3 不断转向其他完成模式时，这可能意味着人们没有通过模仿正确的输出来对其进行足够的约束，并且需要走得更远；可能需要写出目标输出的前几个单词或句子。
> 
> 
> —— Gwren 
> 

# 2 直接提问

Prompt 可以是一个 **提问**，这是最简单常见的方式，可以向ChatGPT提问任何问题。

![](https://files.mdnice.com/user/40454/d2b83a24-5fb9-451d-9cee-daf3c896998d.png)

Prompt 也可以是一些 **指令性** 的任务，包括：

1. **通用的任务：**如「翻译」或「总结」
2. **特定的任务：**用语言去描述出一种特定的任务，比如：
    1. 指定输出的**格式，**如表格、代码块、列表；
    2. 指定输出的**组成部分**，如可以要求输出一遍文章的 背景介绍、正文、结论；
    3. 指定输出的**内容限制**，如内容的长短、不能包括负面信息等；

*无需重新训练模型和教育，便能执行指定任务，被称为 In-context learning 或 0-shot（零样本）*

![通用的任务](https://files.mdnice.com/user/40454/fee31bc2-e720-4632-88f6-4385a92abad6.png)

![特定的任务](https://files.mdnice.com/user/40454/1d65c29c-d171-478c-bd06-e40969f989c5.png)



但是有些任务，ChatGPT并不能完全理解用户的意图，得到的结果便不如人意。

而有些任务是**很难形容**的，或者需要用大量的语言去描述。

应对以上问题便需要用到类比和范畴。

# 3 借助类比和范畴

 ChatGPT 具有一定的**模式识别**能力（尽管还很有限），可以处理复杂的概念，知道某种**范畴**的事物具有怎么的特点，能够发现 prompt 中的文本结构的**规律**，并由此做出各式各类的**类比**。



![这里有2个层次类比，一是每个句子之间关于太阳系与原子的类比，二是从给出的示例1和2，类比出剩下的3，4，5](https://files.mdnice.com/user/40454/93efa348-04b9-44ff-8d95-a4f8d97a2267.png)

这项能力和人类的思维很像。

**范畴和类比是一回事**

> 正是因为能够通过类比进行范畴化，我们才能发现相似的东西，并且利用事物之间的相似性去处理新事和怪事。当我们把刚遇到的新情况，和很早之前就遇到，并且编码处理然后保存在记忆中的先前经历联系起来时，我们就能利用先前的经历来指引现在的行为。作类比是我们大脑功能的重要基石，让我们能够利用从过去经验中获取的丰富智慧，不仅包括已经被贴过标签的概念，如狗、猫、欢乐、辞职、矛盾，等等，也包括没有贴上标签的概念，如上回我出门忘带钥匙结果在寒风中站了几个小时，等等。这些概念，无论具体还是抽象，都会根据当时的情况，在我们大脑找类比的过程中有选择性地、一个接一个地被激活。正是因为有这种无意识却又永不停歇的心理过程，我们才能对自身处境建立心理表征、产生复杂的情感，才能拥有普通寻常或者崇高伟大的思想。没有过去的经历，就没有现在的思想；或者更准确地说，只有用类比将今昔的经验联系起来，思维才有可能存在。
> 
> 
> —— 《表象与本质》侯世达
> 

# 3.1 赋予角色

让ChatGPT**扮演某一个角色**，是范畴的一种常见用法。

例如，可以让ChatGPT**扮演某个人物**甘地、安兰德，而不是直接提问或使用示例来指定道德问题的确切标准。同样也可以和苏格拉底讨论哲学问题，或是扮演学生与老师（**某种职业**）的关系。[更多示例](https://github.com/f/awesome-chatgpt-prompts)。

*有时候，ChatGPT 会跳出角色，重新变回机器人。此时，你可以重新提醒它所扮演的角色。*


![](https://files.mdnice.com/user/40454/7c84cde1-763c-49f7-97b7-3f8475393d01.png)


这种方式不仅会带来复杂的观点，还会带来对问题背景的假设，这原本可能需要很多文字来描述。

让ChatGPT以某个作家的风格进行写作，也属于这个类别。

甚至可以让ChatGPT扮演一些**非人类的事物**，如扮演[虚拟机](https://www.engraved.blog/building-a-virtual-machine-inside/)**。**


![](https://files.mdnice.com/user/40454/c96c9751-706e-4d41-a65e-1659c816ff0c.png)


除了让ChatGPT扮演角色，**用户也可以扮演角色**，如 让ChatGPT向5岁的小孩解释复杂的事物。

*使用中文和英文的效果可能不一样。*


![](https://files.mdnice.com/user/40454/26dd1f8b-30fc-4654-86ef-e0eeab6eb64c.png)


这种方式限于那些被人们普遍认知的范畴，还存在一些难以言明，没有标准语言形容的范畴，这类可以通过类比的方式表达。

# 3.2 运用类比

可以给ChatGPT展示一些 **例子**，展示你想要让它做的事情，ChatGPT会识别例子中存在的**模式**，并**类比**出回答的内容。

使用示例可以有效地传达某些任务。例如，当任务需要特定格式时，示例可能比描述任务本身更简单和具有启发性，从而可以让ChatGPT更好地理解任务的内容。

*这种方式被称为few-shot(小样本) 或 n-shot(n为示例的个数)。*

![让ChatGPT自己发现规律](https://files.mdnice.com/user/40454/577c94d5-5138-41a2-bb5b-aea2e213d04d.png)



对于**复杂的模式**，如果只给几个例子，什么都不说明，ChatGPT可能无法准别识别出来，此时可以加入更多的描述。
prompt 可以参考下面的组合部分：

1. **指令**：描述需要执行的任务，可以包含详细的说明
2. **格式**：指定需要输出的格式
3. **示例**：提供几个示例
4. **输入**：需要处理的数据

*不同部分之间建议使用 —— 或  ``` 分隔开*
![](https://files.mdnice.com/user/40454/662f8172-b234-4e66-99c3-71821764ed61.png)

对于复杂的模式，示例应当：



1. 提供更多的例子**个数**，供ChatGPT学习。
2. 示例应 **多样化**，均匀展示各种情况。比如当限定回答只能是 ”是/否“时，例子中两者个数的比例应该均匀分布，否则ChatGPT的回答可能会倾向于某个选项。

然而示例的数量越多，效果并不是越好，这是一个玄学，需要不断的尝试。

不过由于ChatGPT拥有对话的能力，当ChatGPT没有识别出模式时，可以再给予反馈。

另外，对于那些ChatGPT能够明白的指令，如正常的翻译，应使用直接的指令，使用示例反而会影响效果。

就像人类的思维，不仅需要类比推理，还需要逻辑推理一样，为了让ChatGPT回答好复杂的问题，需要**增强ChatGPT回答的逻辑性**，后面我会介绍如何让ChatGPT能够进行靠谱的逻辑推理。
